# =====================================================================
#  تصدير قاعدة البيانات بأمان إلى سيرفر الإنتاج
# =====================================================================
#  المشكلة التي تحلها الأدوات:
#
#  1) #1452 - بيانات يتيمة في جداول الربط (pivot) تُفشل إضافة قيود
#     المفاتيح الأجنبية عند الاستيراد في الإنتاج.
#
#  2) errno 150 - mysqldump/phpMyAdmin يرتّبان الجداول أبجدياً، فينشأ
#     الجدول الابن قبل الأب فيرفض قيده. هذا يفشل حتى لو لم يفعّل المستخدم
#     خيار "Disable foreign key checks".
#
#  3) فرق التوقيت - بدون SET TIME_ZONE في الملف تتغيّر كل التواريخ
#     بمقدار فرق المنطقة الزمنية بين الخادمين.
#
#  الحل: export_safe.py يصدّر بترتيب طوبولوجي (كل أب قبل أبنه)، ويزيل
#  قيود FK من داخل CREATE TABLE ويعيدها في نهاية الملف، ويضبط
#  TIME_ZONE، فلا يفشل الاستيراد في أي سيناريو.
# =====================================================================

## 1) التحقق من سلامة القاعدة (تشخيص فقط — لا يغيّر شيئاً)

    python scripts/db_export/check_integrity.py

## 2) إصلاح أي بيانات يتيمة + تثبيت القيود الناقصة

    python scripts/db_export/fix_integrity.py

    هذا السكربت:
      - ينظّف الصفوف اليتيمة (يحذف عند CASCADE، ويفوّض NULL عند SET NULL)
      - يضيف قيود المفاتيح الأجنبية الـ 23 حسب تعريفات المايجريشنز

    ملاحظة: المايجريشن Laravel المقابل موجود في:
      database/migrations/2026_09_27_100000_enforce_business_foreign_keys.php
    شغّله على أي بيئة (بما فيها الإنتاج) لضمان بقاء القيود:

      php artisan migrate --database=business

## 3) التصدير الآمن

    python scripts/db_export/export_safe.py -o "C:\path\to\dump.sql"

    أو لملف بدون قيود FK (إذا كنت لا تريدها في الإنتاج):

    python scripts/db_export/export_safe.py -o "C:\path\to\dump.sql" --no-fk

## 4) التحقق قبل النشر (اختياري لكن موصى به)

    يختبر استيراد الملف في قاعدة مؤقتة import_test بأسلوب phpMyAdmin
    مع إعادة تفعيل فحص المفاتيح بعد كل جملة (أقسى سيناريو):

      python scripts/db_export/verify_import.py "C:\path\to\dump.sql"

    النتيجة المطلوبة: "ناجح 100%"

## 5) الاستيراد في الإنتاج

    - افتح phpMyAdmin > Import
    - تأكد من تحديد خانة "Disable foreign key checks" (احتياط إضافي)
    - استورد الملف
    - بعد الاستيراد شغّل: php artisan migrate --force
